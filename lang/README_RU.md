# FapPlugin
**Языки: [English](../README.md), [Русский](README_RU.md)**<br/>

Нужно ли ему объяснение? <br/>

Чтобы остановиться во время `/fap`, нажмите клавишу прыжка дважды за секунду. Удержание не считается.
Подсказка над хотбаром задаётся в `messages.cancel-hint`. Вместо `{key}` показывается клавиша прыжка игрока, обычно Space.
При отмене рекорд не записывается и задержка перед следующим запуском не включается.

# Команды & Разрешения

|    COMMAND    |         DESCRIPTION         |  PERMISSION  |
|:-------------:|:---------------------------:|:------------:|
|    `/fap`     |  Главная команда (Фапать).  |  `fap.use`   |
| `/fap reload` | Перезагрузить конфигурацию. | `fap.reload` |
|    `/pip`     |       Размер шланга.        |  `fap.pip`   |
|               |    Иммунитет к задержке.    | `fap.bypass` |
